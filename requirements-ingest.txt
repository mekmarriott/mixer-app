# Production analysis engine (BPM / beat grid / key / frame features).

# that reason as much as for size: AGPL's copyleft is triggered by network use,
# and this never runs on the network-facing server.
#
# Pinned rather than left floating because the fallback is silent:
# 2.1b6.dev1389 is the newest release publishing macOS arm64 + Linux x86_64
# wheels for CPython 3.9-3.13, while the newer 2.1b6.dev1438 ships cp314 wheels
# only, so an unpinned install quietly drops to the numpy/scipy engine on every
# other interpreter and changes every detected BPM and key. Set
# DJMIXER_REQUIRE_ESSENTIA=1 to make that loud.
#
# rubberband is a CLI, not a package, so it cannot be pinned here — the
# equivalent guard is DJMIXER_REQUIRE_RUBBERBAND=1.
